## 구현할 기능 목록

선 길이 좌표 계산기

1. 선 길이를 구하기 위해 정해진 형식으로 좌표를 입력받는다. 이때 잘못된 형식으로 입력할 경우
다시 입력하라는 메시지와 함께 리젝시킨다. 올바른 형식으로 입력하였다면 선 객체를 생성한다.
2. 두 점간의 직선 거리를 구한다.
3. 좌표평면을 콘솔창에 그려 입력한 좌표에 맞게 점의 위치를 출력한다. 출력은 Y좌표 가장 꼭대기부터 0까지 차례대로 출력하며
두 점의 Y좌표가 겹칠 경우에는 작은 숫자에 해당하는 좌표를 먼저 출력하고 큰 숫자 - 작은 숫자를 하여 그다음 좌표를 출력한다.

* 좌표가 서로 겹칠 때는 좌표를 하나만 표시한다.

사각형 넓이 좌표 계산기

1. 사각형 넓이를 구하기 위해 정해진 형식으로 좌표를 입력받는다. 이때 마름모나 사다리꼴은 해당되지 않으며
오직 직사각형만 입력받는다.
2. 직사각형 좌표의 x최대값, y최대값, x최소값, y최소값만 뽑아내 최대값에서 최소값을 뺀 값으로 넓이를 구한다.
3. 좌표평면을 콘솔창에 그려 입력한 좌표에 맞게 점의 위치를 출력한다. 이때 항상 두 점이 같은 Y좌표에 걸치므로 작은 숫자에 
해당하는 좌표를 먼저 출력하고 큰 숫자 - 작은 숫자를 하여 그다음 좌표를 출력한다.
